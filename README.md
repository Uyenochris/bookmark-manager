# My Bookmark Manager

## What I did

I made a website to save bookmarks. I picked School, Tools, Fun, and Other for my categories. I put the bookmarks in an array and each one has a title, url, and category.

There are 2 pages, one for seeing the bookmarks and one for adding them. I used #all and #add and some JavaScript to hide whichever page isn't being used. I did it that way so it doesn't actually load a new page.

When you fill out the form it adds the stuff into my array. The list shows the websites and you can delete them too. I saved the array using JSON and localStorage so the websites will still be there when it reloads. Editing uses a prompt box. I can change the title and link but I haven't done changing the category yet. I also had trouble with making the edits stay there after I reload it.

## AI use

I used AI to help with the CSS colors, navigation styling, spacing and the empty list message. I wrote the HTML layout and JavaScript parts myself.

## Files

- index.html
- styles.css

I put these files together in one folder. Open index.html to see the site.
